# MPU6050驱动实现

## MPU6050简介

MPU6050是一款六轴IMU（惯性测量单元），集成3轴加速度计和3轴陀螺仪，通过I2C接口通信。

- I2C地址：`0x68`（AD0=低）或 `0x69`（AD0=高）
- WS63开发板对应：GPIO15（SCL）、GPIO16（SDA）

---

## 重要坑点：地址与寄存器

> MPU6050数据读取**不是**从固定地址 `0x3B` 开始随便读。
> 正确流程：向 `0x3B`（ACCEL_XOUT_H）写入起始地址，然后**连续读取14字节**（加速度6字节+温度2字节+陀螺仪6字节）。

```c
// 错误做法：每次单独读单个寄存器
// uint8_t xh = i2c_read_reg(MPU_ADDR, 0x3B);  // 不推荐

// 正确做法：连续读14字节
uint8_t buf[14];
i2c_read_regs(MPU_ADDR, 0x3B, buf, 14);

int16_t accel_x = (buf[0] << 8) | buf[1];
int16_t accel_y = (buf[2] << 8) | buf[3];
int16_t accel_z = (buf[4] << 8) | buf[5];
// buf[6] buf[7] 是温度
int16_t gyro_x  = (buf[8]  << 8) | buf[9];
int16_t gyro_y  = (buf[10] << 8) | buf[11];
int16_t gyro_z  = (buf[12] << 8) | buf[13];
```

---

## 初始化序列

```c
void mpu6050_init(void)
{
    // 唤醒（写0x00到PWR_MGMT_1寄存器0x6B）
    i2c_write_reg(MPU_ADDR, 0x6B, 0x00);
    // 设置采样率分频（SMPLRT_DIV = 0x07 → 1KHz/(1+7)=125Hz）
    i2c_write_reg(MPU_ADDR, 0x19, 0x07);
    // 配置低通滤波器（DLPF_CFG = 0x06 → 5Hz）
    i2c_write_reg(MPU_ADDR, 0x1A, 0x06);
    // 加速度量程 ±2g
    i2c_write_reg(MPU_ADDR, 0x1C, 0x00);
    // 陀螺仪量程 ±250°/s
    i2c_write_reg(MPU_ADDR, 0x1B, 0x00);
}
```

---

## 数据转换

```c
// 加速度：灵敏度 16384 LSB/g（±2g量程）
float ax = accel_x / 16384.0f;  // 单位：g
float ay = accel_y / 16384.0f;
float az = accel_z / 16384.0f;

// 陀螺仪：灵敏度 131 LSB/°/s（±250°/s量程）
float gx = gyro_x / 131.0f;    // 单位：°/s
float gy = gyro_y / 131.0f;
float gz = gyro_z / 131.0f;
```

## WS63 I2C配置

在SDK中找到I2C初始化函数，注意GPIO功能复用配置：

```c
// GPIO15 → I2C_SCL, GPIO16 → I2C_SDA（根据实际SDK宏定义）
// 在SDK源码中搜索：grep -r "gpio_func_mux" drivers/
io_set_func(GPIO15_MUX_FUNC_I2C_SCL);
io_set_func(GPIO16_MUX_FUNC_I2C_SDA);
```

> **坑点**：官方原理图标注的GPIO与SDK中的宏定义可能不一致，以SDK源码为准！
