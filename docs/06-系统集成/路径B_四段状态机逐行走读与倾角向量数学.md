## 〇、一句话与判据总表

只看一个标量 **`acc = |三轴加速度|`（单位 g）**：静止≈1G、失重≈0、撞击>1G。跌倒 = 特定的 `acc` 变化序列。

```
IDLE ─失重─▶ FREEFALL ─失重结束┬即冲击─▶ POST_IMPACT ─观察1s─▶ 确认/否决
                              └等冲击─▶ IMPACT_WAIT ─冲击─┘
任一段不满足 → fall_algo_reset() 回 IDLE
```

| 判据 | 阈值(200Hz/腰部) | 在哪验 | 挡掉的假动作 |
|---|---|---|---|
| ①自由落体 | \|acc\|<0.75G，持续 14~150 样本(70~750ms) | FREEFALL | 抖动 / 异常 |
| ②硬冲击 | 峰值 \|acc\| ≥ 4.0G(触发线 2.2G) | POST_IMPACT 收尾 | 快速蹲下/坐下(冲击柔) |
| ③冲击后静止 | 跳过0.5s沉降,观察1s,静止占比≥50%(\|acc\|∈[0.6,1.4]G) | POST_IMPACT 收尾 | 剧烈摇晃 |
| ④倾角 | 冲击前后重力方向夹角 ≥45° | POST_IMPACT 收尾 | 原地起跳落地(躯干直立) |

## 一、ST_IDLE —— 等失重 + 维护直立方向参考

```c
if (acc >= 0.85 && acc <= 1.15) {          // 只在静止(≈1g,纯重力)时更新
    if (!s_gref_valid) { s_gref = a; valid=1; }        // 首次:直接初始化
    else { s_gref += 0.02*(a - s_gref); }               // 之后:指数低通(EMA)平滑跟踪
}
if (acc < 0.75) { s_state=FREEFALL; s_ff_count=1; s_ff_min=acc; }  // 失重→进自由落体段
```
- `s_gref` = "人直立时重力朝哪"，给④倾角判据当**事件前基准**。用 **EMA（`new=old+α(cur-old)`，α=0.02）** 慢慢跟踪、滤噪声，且**只在静止时更新**（动的时候 acc 混了运动分量，会污染方向）。
- `s_gref` 在 `reset()` 里**不清**——是长期基准。
- 进 FREEFALL 的三行是初始化：切状态、失重计数从 **1** 起（当前帧就是第1个失重样本）、记失重最低点初值。

## 二、ST_FREEFALL —— ①自由落体判据（验时长）

```c
if (acc < s_ff_min) s_ff_min = acc;           // 记失重最低点(调参用)
if (acc < 0.75) { s_ff_count++; if(>150) reset(); }  // 还在失重;>750ms=异常否决
else if (s_ff_count < 14) reset();            // 失重<70ms=抖动否决
else if (acc > 2.20) { →POST_IMPACT ... }     // 失重结束即冲击
else { →IMPACT_WAIT ... }                     // 失重结束但没冲击,去等
```
> ★①判据：**失重必须持续 14~150 样本**。太短(抖动)太长(异常)都否决。

## 三、ST_IMPACT_WAIT —— 限时等硬冲击

```c
s_wait_count++;
if (acc > 2.20) { →POST_IMPACT; s_impact_max=acc; ... }  // 冲击来了
else if (s_wait_count > 200) reset();                    // ~1s没冲击=轻放/起跳,否决
```

## 四、ST_POST_IMPACT —— 观察静止 + 收尾判 ②③④

分三阶段（靠 `s_post_count` 计时，SETTLE=100/0.5s，WINDOW=200/1s）：
```c
s_post_count++;
if (acc > s_impact_max) s_impact_max = acc;   // 持续追冲击峰值(回弹/二次冲击)

if (s_post_count <= 100) break;               // [阶段1] 前0.5s沉降期:翻滚/回弹,跳过不统计

if (acc∈[0.60,1.40]) {                        // [阶段2] 静止样本
    s_still_count++;
    s_gpost += a; s_gpost_n++;                //   累加重力方向,求事件后躯干朝向(供④)
}

if (s_post_count >= 300) {                    // [阶段3] 满1.5s → 收尾判决(只一次)
    pct  = s_still_count*100/200;             // ③静止占比%
    tilt = fall_algo_tilt_deg();              // ④倾角(见下节)
    soft = s_impact_max < 4.0;                // ②冲击太柔?
    reset();                                  // ★先复位(需要的值已存进局部变量)
    if      (pct < 50)  reject ③;             // 不够静止(还在动)
    else if (soft)      reject ②;             // 软冲击(蹲/坐)
    else if (tilt < 45) reject ④;             // 躯干直立(起跳)
    else { return 1; }                        // ①②③④全过 → 确认!
}
```
要点：
- **持续追 `s_impact_max`**：撞地常有回弹/二次冲击，峰值可能晚几帧出现。
- **跳过 0.5s 沉降**：刚落地在翻滚，不能算"静止"。
- **先 `reset()` 再判**：判决用的 `pct/tilt/soft` 已先算好存进局部变量；reset 清全局后用局部值决定打印/返回。顺序：**先算(读全局)→reset→再判**。
- `im_i/im_f` 那几行是把浮点拆成 `%d.%02d`，因嵌入式 printf 常不支持 `%f`，纯为日志。

## 五、④倾角判据的向量数学（`fall_algo_tilt_deg`）

**目标**：求"事件前直立方向 `s_gref`"与"事件后平均方向 `p`"的夹角。夹角大=倒了，小=仍直立。

**核心公式（两向量夹角）**：
```
        A·B                A·B = Ax·Bx+Ay·By+Az·Bz   (点积)
cos θ = ───────  ,          |A| = √(Ax²+Ay²+Az²)       (模长)
        |A|·|B|
θ = arccos(cos θ)
```
> 为什么点积能求夹角？恒等式 `A·B = |A||B|cos θ` 移项即得。点积衡量两向量"多同向"：平行 cos=1(θ=0)、垂直 cos=0(θ=90°)、反向 cos=-1(θ=180°)。

**逐行**：
```c
if (!s_gref_valid || s_gpost_n==0) return 180;   // 信息不足→返回180(=已倒,不被④否决,保守不漏报)
p = s_gpost / s_gpost_n;                          // 事件后平均方向(求平均滤噪)
rn = |s_gref|;  pn = |p|;                          // 两向量模长
if (rn<0.01 || pn<0.01) return 180;                // 退化→保守返回180
cosang = (s_gref·p) / (rn*pn);                     // = cos θ。除以模长=只比方向不看大小
if (cosang>1) cosang=1; if (cosang<-1) cosang=-1;  // 夹逼[-1,1]:浮点舍入超范围会让acos返回NaN
return acos(cosang) * 57.2958;                     // 弧度→度(×180/π)
```

**朝向无关的巧思**：比较的是同一传感器**事件前 vs 事件后**的重力读数，只看变化量——安装朝向在"相减/求夹角"里自然抵消，剩下的纯粹是身体转了多少度。

**数值例子**（设直立 `s_gref=(0,0,1)`）：
| 动作 | 事件后 `p` | 点积 | cos | θ | 结果 |
|---|---|---|---|---|---|
| 跌倒躺地 | (1,0,0) | 0 | 0 | **90°** | ≥45 通过 ✔ |
| 起跳落地站着 | (0,0,1) | 1 | 1 | **0°** | <45 否决 ✔ |

## 六、五种否决 vs 一种确认

| 结果 | 触发 | 挡掉 |
|---|---|---|
| 否决 | 失重<70ms / >750ms | 抖动 / 异常 |
| 否决 | 1s 内无冲击 | 轻放 / 起跳(无撞击) |
| 否决 | 静止<50% | 剧烈摇晃 |
| 否决 | 冲击<4G | 蹲下 / 坐下 |
| 否决 | 倾角<45° | 原地起跳落地 |
| **确认** | 全不触发 | **失重→硬冲击→躺地不动→躯干倾倒** |

## 七、一句话

> 路径B 是只看合加速度 `acc` 的四段状态机：IDLE 等失重(顺带 EMA 跟踪直立方向)→ FREEFALL 验失重时长(①)→ IMPACT_WAIT 限时等冲击 → POST_IMPACT 跳沉降后观察 1s，收尾同时判 ②硬冲击/③静止/④倾角，四项齐全才 `return 1`。④倾角用**向量夹角公式**比较事件前后重力方向，与安装朝向无关。
